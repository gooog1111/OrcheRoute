# OrcheRoute UI

> Общий статус всего проекта: [PROJECT_STATUS.md](../PROJECT_STATUS.md).

Единое статическое React-приложение для трёх оболочек:

- **WebUI / server** — статическая сборка обслуживается `orcheroute-server`;
- **Desktop** — интерфейс уже упакован в нативную Wails-оболочку;
- **Android** — интерфейс встроен в APK и обслуживается через
  `WebViewAssetLoader` без HTTP-сервера.

Компоненты не знают API-токен и обращаются только к относительному `/api`.
Серверный шлюз добавляет авторизацию к запросу уже на loopback-интерфейсе.
Desktop-оболочка заменяет транспорт внутренним Go handler. Android пока
возвращает `mobile_runtime_not_started`, потому что `VpnService` и Mihomo ещё не
встроены.

## Разработка

```bash
npm install
npm run dev
```

Для локальной разработки нужен proxy `/api` к тестовому backend или mock.

## Проверка и сборка

```bash
npm run lint
npm test
```

Статический результат создаётся в `out/`, устанавливается на сервер в
`/opt/orcheroute/webui` и встраивается в Desktop/Android при их сборке.

## Текущий экран

- сводный статус WAN, узлов, маршрутов и режима контроллера;
- главный переключатель VPN/bypass;
- модальные настройки;
- автоматический или ручной выбор узла;
- состояние сетевого профиля, DNS и маршрутов;
- список подписок и запуск их обновления;
- адаптивная мобильная компоновка.
