# OrcheRoute

[English](README.en.md)

VPN-клиент для Android и VPN-контроллер с веб-интерфейсом для Linux Server на базе [Mihomo](https://github.com/MetaCubeX/mihomo). Поддерживает подписки, проверку серверов, DNS и маршруты `direct`, `proxy`, `block`.

## Android

Требуется Android 8.0 или новее; root не нужен.

1. Установите APK и подтвердите разрешение на создание VPN.
2. Добавьте подписку, импортируйте файл, ссылку или QR-код. При необходимости включите встроенные аварийные источники.
3. Обновите подписку и проверьте серверы — отдельно по подписке или весь список.
4. Выберите сервер вручную и нажмите «Включить».

Список серверов сгруппирован по подпискам. Выбранный вручную сервер остаётся закреплённым. В уведомлении доступны кнопки «Перезапустить» и «Выключить».

Для FreeTURN подтвердите VK CAPTCHA, если появится запрос. Окно можно перемещать за заголовок.

В разделе «Обновления» можно проверить и установить новую версию. Флажок «Бета-версии» выбирает тестовый канал; для стабильных обновлений выключите его.

Разрешите уведомления и фоновую работу приложения. Экспорт подписок доступен в настройках.

## HWID подписок

В настройках «Подписки» можно сохранить HWID под своими названиями и скопировать HWID текущего устройства. При добавлении или редактировании HTTPS-подписки выберите сохранённый идентификатор, текущее устройство или введите свой. По умолчанию HWID не отправляется.

Выбранный идентификатор сохраняется и не меняется при обновлении подписки. Используйте идентификатор устройства, разрешённого вашим провайдером подписки.

## Linux Server

Установка в Debian/Ubuntu:

Обязательные пакеты: `ca-certificates`, `iproute2`, `systemd`, `nftables`, `iptables`, `curl`, `tar`, `gzip`, `dpkg`, `apt` и одна служба времени: `systemd-timesyncd`, `chrony`, `ntpsec` или `ntp`. APT устанавливает зависимости вместе с DEB.

```bash
sudo apt install ./OrcheRoute-Linux-Server-0.8.5-amd64.deb
```

Откройте `http://127.0.0.1:19110/` на сервере либо `http://АДРЕС_СЕРВЕРА:19110/` с другого устройства. Данные первого входа выводятся установщиком и сохраняются в `/etc/orcheroute/initial-credentials`. Для внешнего доступа настройте HTTPS в разделе «Доступ».

Проверить состояние службы:

```bash
systemctl status orcheroute-go --no-pager
```

1. В разделе «Сеть и DNS» выберите интерфейсы прямого доступа, подключения к VPN-серверам и перехвата трафика.
2. Добавьте подписки и задайте интервалы их обновления.
3. Проверьте серверы — по одной подписке или весь список.
4. Выберите ручное или автоматическое управление и включите VPN.

Плановое обновление загружает подписки, а проверка серверов запускается отдельно.

В автоматическом режиме используется основной список, затем аварийный. Для белых списков формируется отдельный список доступных серверов. Выбор учитывает рейтинг и стабильность соединения. В ручном режиме выбранный сервер остаётся закреплённым.

### DNS и время

Для DNS доступны отдельные настройки Direct, Proxy, VPN-сервера и Bootstrap. Монитор сети и определение Direct IP используют DNS выбранного физического интерфейса; резерв задаётся в Bootstrap. Изменения DNS интерфейса подхватываются автоматически.

На главной странице отображаются дата, время и часовой пояс сервера. В разделе «Обновления» нажмите «Синхронизировать время», чтобы включить системную синхронизацию NTP. Рядом отображается её состояние.

### Квалификация серверов

Проверки включают TCP, открытие контрольных URL, фактический регион выхода и скорость. Рейтинг учитывает задержку, скорость и стабильность. Проверка одной подписки сохраняет оценки остальных.

Измерители скорости: Cachefly, Cloudflare и OVH. Если замер недоступен, работоспособность подтверждается повторной URL-проверкой, а скорость остаётся неопределённой.

В разделе «Квалификация» настраиваются контрольные URL, таймауты и фильтры. Дополнительный фильтр открытия адреса поддерживает три режима:

- выключен;
- допускать сервер, если адрес открывается;
- отклонять сервер, если адрес открывается.

Адрес, например `youtube.com`, проверяется через каждый VPN-сервер после обычного URL-test. Успешным считается HTTP `2xx`.

### Собственный VPN-сервер

Раздел «VPN-сервер» позволяет выдавать персональные подписки с FreeTURN, VLESS Reality, Trojan TLS и Hysteria2. Для подписки можно задать срок действия, лимит трафика и доступ к локальной сети сервера: наследовать общую настройку, разрешить или запретить отдельно.

Стандартные порты: FreeTURN UDP `4443`, VLESS TCP `24443`, Trojan TCP `24444`, Hysteria2 UDP `24445`. Откройте используемые порты в своём firewall. Публичный адрес может быть IP или доменным именем; адрес HTTPS-подписки задаётся отдельно. Стандартный SNI — `m.vk.ru`.

### Обновление и удаление

Обновление доступно в разделе «Обновления» веб-интерфейса или установкой нового DEB поверх предыдущего. Авторизация, подписки и настройки сохраняются.

```bash
sudo apt remove orcheroute  # сохранить настройки и авторизацию
sudo apt purge orcheroute   # удалить настройки, состояние и резервные копии
```

## Маршруты и GEO

Правила поддерживают IP, CIDR, диапазоны адресов, домены, GeoIP/GeoSite, протоколы и порты. Действия: `direct` — напрямую, `proxy` — через VPN, `block` — блокировать.

Источник GeoIP/GeoSite и расписание обновлений выбираются в настройках. Доступны:

- [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat): [GeoIP](https://github.com/MetaCubeX/meta-rules-dat/releases/download/latest/geoip.dat), [GeoSite](https://github.com/MetaCubeX/meta-rules-dat/releases/download/latest/geosite.dat);
- [RunetFreedom/russia-v2ray-rules-dat](https://github.com/runetfreedom/russia-v2ray-rules-dat): [GeoIP](https://raw.githubusercontent.com/runetfreedom/russia-v2ray-rules-dat/release/geoip.dat), [GeoSite](https://raw.githubusercontent.com/runetfreedom/russia-v2ray-rules-dat/release/geosite.dat);
- [Loyalsoldier/v2ray-rules-dat](https://github.com/Loyalsoldier/v2ray-rules-dat): [GeoIP](https://github.com/Loyalsoldier/v2ray-rules-dat/releases/latest/download/geoip.dat), [GeoSite](https://github.com/Loyalsoldier/v2ray-rules-dat/releases/latest/download/geosite.dat).

Можно указать свои HTTPS-ссылки на совместимые базы.
